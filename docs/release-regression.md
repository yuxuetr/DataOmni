# 发版前回归清单

在**打包版**上按这份单子走一遍，结果记进 `TODOs.md` 的「P0-P3 无阻塞级缺陷」。单测与 `bun run check` 抓不到的
（白屏、占位符没替换、焦点乱跳、截断、插件对话框不弹）只有在这里看得到。

规矩：

- 一个库走满全部通用项（第一节到第八节），其余库只走与方言相关的那几项（第九节）。
- 每一项写结论：过 / 修了（提交号）/ 没修（理由与重估条件）/ 没测（为什么）。
- 修了的在新包上复验那一项，并顺带把同一区域再点一遍。

## 一、连接

- [ ] 新建：填表、测试连接、保存；口令进系统钥匙串，重启后免输入连上
- [ ] 编辑已有连接、改名；删除连接走应用内确认框
- [ ] 连不上：错主机 / 错口令 / 错库名各一次，提示说得出原因
- [ ] TLS 必需的库连上；SSH 隧道连上
- [ ] 打开数据库文件（SQLite / DuckDB）

## 二、对象树

- [ ] 展开库 / schema / 表 / 视图 / 函数，筛选框
- [ ] 右键菜单各项能用（打开数据、结构、新建查询、复制名字、删除走确认）

## 三、SQL 编辑与执行

- [ ] 执行当前 / 选中 / 全部；多条结果逐条收起
- [ ] 报错定位到行；危险语句（无 WHERE 的 UPDATE / DELETE、DROP）先确认
- [ ] 取消一条长查询
- [ ] 补全（表名、列名）、格式化、查找替换
- [ ] 打开 / 保存 `.sql` 文件，⇧⌘S 另存
- [ ] 标签：新建、⌘W、关闭其他、最近关闭、⌘1…9；重启后标签与草稿还在
- [ ] 查询历史：搜索、重新打开

## 四、查询结果

- [ ] 排序、选区、复制（TSV）、复制成 INSERT
- [ ] 在结果里直接改一格并提交
- [ ] 快速图表
- [ ] 导出结果（CSV / JSON / INSERT 语句）

## 五、表数据

- [ ] 翻页、排序、筛选、清空筛选
- [ ] 改格、新增行、删行、撤销单条、提交；冲突时（别处改过）提交被拒
- [ ] 只读表（无主键）说明原因

## 六、表结构

- [ ] 看列、索引、外键、DDL
- [ ] 改列、加列、加索引：预览语句、执行
- [ ] 新建表；ER 图；数据字典导出

## 七、事务、导入导出、备份

- [ ] 开事务、改、回滚 / 提交；事务中网格提交走同一会话；关窗口时询问
- [ ] 导入 CSV（映射、类型提示、跳过坏行）
- [ ] 整表导出；备份与还原
- [ ] 执行计划

## 八、应用

- [ ] 主题（浅 / 深 / 跟随系统）、语言（中 / 英），英文界面没有漏翻与 `{占位符}`
- [ ] 命令面板、快捷键

## 九、各库的方言项

| 库 | 走哪几项 |
| --- | --- |
| PostgreSQL | 数组 / jsonb / 时间戳编辑，执行计划，失败事务，断线重连 |
| MySQL | TLS，`_bin` 文本，执行计划，备份 |
| SQLite | 文件打开，无类型列，备份 |
| DuckDB | 文件打开，导入只能分批跳过 |
| ClickHouse | 浏览与查询，改一行 |
| SQL Server / Oracle | 连接，浏览，改一行，执行计划 |
| MongoDB | 浏览、增删改、聚合、命令台 |
| Redis | 逻辑库、六种类型、命令行与危险命令确认 |
| Neo4j | Cypher 执行、图视图、改属性 |
| Elasticsearch | 索引浏览、查询台、改文档 |
